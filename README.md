# 人文家庭电影感短剧 Skill

面向 Lumina 画布 Agent 的短剧创作 Skill。它把一句话故事、已有梗概或视听参考发展为脚本、人物与场景锚点、分镜、关键帧、逐镜视频、声音方案和画布编排。

## 导入

在 Lumina 的 Skill 导入界面粘贴本仓库地址，入口文件为 `SKILL.md`。

本仓库的普通文件均使用 Lumina 支持的小写文本扩展名。许可证命名为 `license.md`，因此不会触发无扩展名 `LICENSE` 的导入报错。参考图片、视频和生成结果不打包进仓库。

## 两种模式

- 观察式家庭短剧：日常事件、克制对白、固定中景、生活环境声与开放余韵。
- 记忆诗篇：参考用户给出的诗意视频，用现实锚点串联碎片化回忆，并限制超现实意象，避免做成炫技 MV。

两种模式都不会在下游生成提示词中使用在世导演姓名，也不会复制具体电影或参考视频的角色、对白、情节与标志性镜头。

## 文件结构

```text
SKILL.md
README.md
license.md
references/
  aesthetic.md
  canvas-workflow.md
  prompt-patterns.md
  quality-check.md
  reference-video.md
```

隐藏文件 `.skillignore` 仅服务于 Skill 打包，不包含运行时素材。

## 示例请求

> 一个多年没有回家的女儿，在台风前夜陪父亲给阳台上的旧花盆换土。做成 75 秒横屏短剧，普通话对白。

> 参考我上传的记忆短片，把“拆掉老理发店前的最后一天”做成 80 秒无对白短片；保留碎片化回忆和静止长镜头，但不要复制参考片中的具体意象。

第一次运行建议先检查创作简报、人物锚点和场景锚点，再让 Agent 批量生成镜头。
