# 人文家庭电影感短剧 Skill

这是一个面向 Lumina 画布 Agent 的短剧创作 Skill。它把一句话故事发展为脚本、分镜、关键帧、逐镜视频与声音方案，重点营造家庭关系、日常观察、克制表演、自然光和开放余韵。

## 导入

在 Lumina 的 Skill 导入界面粘贴本仓库地址，或上传整个文件夹。入口文件是 `SKILL.md`。

仓库只包含 Lumina 导入器支持的纯文本文件；所有扩展名均为小写。许可证文件使用 `license.md`，没有使用会触发导入报错的无扩展名 `LICENSE`。

## 文件结构

```text
SKILL.md
README.md
license.md
references/
  aesthetic.md
  prompt-patterns.md
  quality-check.md
```

## 设计边界

本 Skill 不要求模型复刻任何在世导演的独特风格，也不会把导演姓名写入生成提示词。它将相关参考转译为可执行的高层电影语言，并避免复制具体作品的情节、角色、对白和标志性镜头。

## 建议用法

启用 Skill 后可以直接发送：

> 一个多年没有回家的女儿，在台风前夜陪父亲给阳台上的旧花盆换土。做成 75 秒横屏短剧，普通话对白。

第一次运行建议先检查脚本、人物锚点和场景锚点，再让 Agent 批量生成剩余镜头。
