# 提示词结构

以下是结构模板，不是必须逐字复制的文案。每个镜头都要填入具体人物、场景和动作，并完整重复连续性锚点。

## 图像提示词

```text
[画幅]，写实真人电影画面。[人物锚点]位于[场景锚点]，正在进行[单一可见动作]。[人物之间的空间关系与视线]。[景别]，[机位高度与角度]，[固定构图或框中框关系]。[时间、天气、主光方向]，自然肤色，低饱和中性色，适中景深，保留生活痕迹，细腻但不过度锐化，轻微胶片颗粒。情绪通过[手部动作/停顿/物件]含蓄呈现。无文字，无水印，无品牌标识。
```

## 视频提示词

```text
持续[5/10]秒，延续参考图中的人物身份、服装、场景布局、光线和色彩。镜头从[起始画面]开始。[人物]完成[一个连续动作]，在[具体时刻]出现[细微表情或视线变化]，最后停在[结束画面]。摄影机[固定/缓慢平移/轻微跟随/极慢推进]，运动平稳且有叙事动机。保持自然速度和真实物理，不新增人物或物件，不改变脸部、服装、天气与空间结构，无镜头跳变，无肢体畸变，无文字水印。
```

## 声音提示词

```text
真实室内/室外环境声，近处[动作细节声]，中景[持续环境声]，远处[空间延伸声]。对白自然、音量稳定、保留短暂停顿。无夸张混响，无预告片式冲击音。若使用音乐：少量原声乐器、节奏稀疏、音量低于对白，在[具体节点]进入并于[具体节点]退出。
```

## 分镜条目示例

```text
镜 04｜10 秒｜厨房，中景，固定机位
动作：母亲把多盛的一碗饭推到空座位前，停一下，又拉回自己面前。
声音：电饭煲保温声；走廊里有人关门；无音乐。
起始：两人相对坐着，空座位在画面右侧。
结束：母亲低头夹菜，孩子看向那只空碗。
连续性：人物服装、餐桌方向、右侧窗光和三只不同颜色的碗与基准图一致。
```

这个例子只说明信息密度。不要在新故事里复用其中的情节或构图。
